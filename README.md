# 第 8 项 · 体育博彩：五大联赛赔率结构与投注价值检验

《商业数据分析》期末大作业（第 8 项选题）的可复现代码与成果仓库。

---

## 一、这份作业回答什么

用 Football-Data.co.uk 的 **35,981 场**欧洲联赛赛果与赛前赔率，回答四个定价问题：

| 问题 | 方法 | 结论（正文可查） |
|---|---|---|
| 市场在变「厚」还是变「薄」 | 抽水率趋势 + MA3 | 7.17% → **5.10%**，15 年降 2.07 个百分点，14 次环比 10 次为负 |
| 各联赛差多少 | 联赛对比 + 热力 + 气泡 | 英超 4.77%（最低）↔ 葡超 6.82%（最高），差 2.05 个百分点 |
| 市场定价准不准 | Brier / LogLoss / 分档校准 | Brier **0.5705**、LogLoss 0.9609；散点贴 45° 线，但热门端被系统性低估 |
| 照策略下注能赚吗 | 逐注回测 ROI | 三种盲投 −105.61% / −102.67% / −103.13%，与理论返还率 94.39% 吻合 |
| 模型能跑赢市场吗 | 逻辑回归 vs 市场 / ARIMA | 仅领先 **0.0005** Brier；ARIMA 的 MAPE 8.22% **劣于**朴素 7.58% |

> 最后一条是本文最重要的「负结果」：在高效定价的市场里，**预测更准 ≠ 能赚**。

## 五、关键工程处理（踩过的坑 & 解法）

1. **三代列结构变迁**（本项目最大的工程难点）：
   - 2010/11—2011/12：只有少量公司赔率；
   - 2012/13—2018/19：扩展到 10 余家，并新增 `AvgH/AvgD/AvgA` 聚合列；
   - 2019/20 之后：改用 `B365`、`PS` 等新代码并逐步停用旧列。

   解法：`pick()` 三级回退——「Avg 聚合列 → Betbrain `BbAv*` → 各公司均值」，按缺失率自动降级。
2. **抽水率口径**：采用 `1/主胜赔 + 1/平局赔 + 1/客胜赔 − 1`（等价于 `1 − 返还率`），
   不用「除以总和再归一化」的口径——后者会把抽水率人为压到 0，掩盖真实毛利。
3. **K-Means 的 K=2**：轮廓系数在 K=2 时最高（0.458），且两类可直接命名为
   「低效闷战局 / 强弱悬殊局」。这与「K 取 4—6」的惯例不同，原因是赔率空间只有两个主方向。
4. **多分类 log_loss**：sklearn 传 `labels=[0,1]` 会要求 multilabel 输入，
   改为手写 `-mean(sum(Y * log(clip(P))))`。
5. **概率校准表的单位**：源表「实际命中率」是 0—1 小数，而「隐含概率」是百分数，
   直接画图会全部堆在原点；绘图前需统一乘 100（已在 `fig12()` 中加判断）。
6. **回测口径**：按**最高可得赔率**成交（对策略最有利的假设），
   若用平均赔率 ROI 会更差——这是刻意选择的保守披露方式。

## 六、AI 使用披露

- **AI 参与的**：代码初稿生成与调试、文字润色。
- **AI 未参与的**：数据源选择与合规判断、模型选型（如 K=2 的业务理由）、
  「模型跑不赢市场」这一结论的解读、全部商业建议。
- **核验方式**：正文每个数字都可由 `outputs/stats.json` 或 `outputs/tables/*.csv` 复算；
  图表由 `04_visuals.py` 一键重绘。
