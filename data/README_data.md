## 二、获取方式（合规说明）

1. **不是爬虫**：脚本按「赛季 + 联赛代码」拼出确定的文件 URL，逐一 `HTTP GET` 下载。
   不解析 HTML、不遍历链接、不模拟点击、不设置伪装 UA。
2. **有节制**：105 个文件总耗时 297.7 秒（平均 2.8 秒/文件），请求间隔天然分散。
3. **无门槛**：站点公开提供免费下载，无需注册、无需 API Key、无需付费。
4. **可校验**：`_manifest.csv` 逐文件记录 `sha256`，可下载后比对确认是同一份数据。

## 三、`_manifest.csv` 字段

| 字段 | 说明 |
|---|---|
| `文件` | 本地文件名，格式 `{联赛代码}_{赛季代码}.csv` |
| `联赛代码` | E0 / D1 / SP1 / I1 / F1 / N1 / P1 |
| `联赛` | 联赛英文全名 |
| `赛季` | 赛季代码（1011 = 2010/11） |
| `来源链接` | 完整下载 URL |
| `字节数` | 文件大小 |
| `sha256` | 内容哈希 |
| `获取时间` | ISO 8601 时间戳 |
| `获取方式` | 固定为「HTTP GET 直链下载（urllib，无登录/无 API Key）」 |

## 四、⚠️ 三代列结构变迁（本项目最大的坑）

同一字段在不同年代的列名完全不同，**不能按固定列名读取**：

| 时期 | 特征 | 取列策略 |
|---|---|---|
| 2010/11 — 2011/12 | 仅少量公司赔率，无聚合列 | 取各公司均值 |
| 2012/13 — 2018/19 | 扩展到 10 余家，新增 `AvgH` / `AvgD` / `AvgA` | 优先用 `Avg*` |
| 2019/20 — 2024/25 | 改用 `B365*`、`PS*`，旧列逐步停用 | `Avg*` → `BbAv*` → 各公司均值 |

`scripts/02_clean.py::pick()` 实现了三级回退，并按「非空率 > 0.6」判断某列是否可用。

## 五、核心字段与派生指标

原始字段（节选）：

| 组 | 字段 | 含义 |
|---|---|---|
| 标识 | `Date`、`HomeTeam`、`AwayTeam` | 比赛主键 |
| 赛果 | `FTHG`、`FTAG`、`FTR` | 全场主客进球与结果（H/D/A） |
| 半场 | `HTHG`、`HTAG`、`HTR` | 半场比分与结果 |
| 技术统计 | `HS`、`AS`、`HST`、`AST`、`HC`、`AC` | 射门、射正、角球 |
| 平均赔率 | `AvgH`、`AvgD`、`AvgA` | 本文主口径 |
| 最高赔率 | `MaxH`、`MaxD`、`MaxA` | 策略回测用 |
| 大小球 | `Avg>2.5`、`Avg<2.5` | 大 2.5 球盘口 |

派生指标（10 个）：总进球、大 2.5 球、双方进球、主胜/平局/客胜、隐含主胜/平局/客胜概率、
**抽水率**、主场优势、最大/最小隐含概率、赛季、月份、年季序。

**抽水率定义**：

```
抽水率(%) = (1/平均主胜赔 + 1/平均平局赔 + 1/平均客胜赔 − 1) × 100
```

它等价于「1 − 返还率」，是博彩公司在每一注上的理论毛利率。

## 七、声明
